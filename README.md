# claude-certification

My notes and experiments while studying for the **Claude Certified Architect – Foundations** certification.

## What's here

- Notes from the [Anthropic Academy](https://anthropic.skilljar.com/) courses and the [Claude Code docs](https://code.claude.com/docs/en/overview)
- Small experiments that try out what the courses teach (the Claude API, MCP, Agent Skills, Claude Code)

## Study plan

In order:

1. Introduction to Agent Skills
2. Claude with the Anthropic API
3. Introduction to Model Context Protocol
4. Claude Code in Action
5. Claude Code docs and videos
6. Claude Agent SDK: the Introduction to subagents course, the [Agent SDK docs](https://code.claude.com/docs/en/agent-sdk/overview) and a hands-on exercise

## Layout

- `courses/<course>/notes.md`: takeaways, open questions and exam-relevant points per course or reading list
- `experiments/<name>/`: runnable experiments, each with its own README
